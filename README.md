# SexScenarioBot — Telegram-бот для генерации эротических сценариев для пар

Бот связывает двух людей в пару, собирает их сегодняшние предпочтения, место, время и стиль, и генерирует персональный сценарий через DeepSeek.

## Новые возможности

- Выбор **стиля** сценария (нежный, грязный, доминирование, игривый, жёсткий, классический)
- Кнопка **«Другой вариант»** — генерирует новый сценарий в том же стиле
- Кнопка **«Другой стиль»** — позволяет сменить характер сценария и сразу получить новый

## Быстрый старт (с компьютера)

```bash
cd SexScenarioBot
python -m venv venv
source venv/bin/activate          # Linux / macOS
# или venv\Scripts\activate       # Windows

pip install -r requirements.txt
```

Создай/отредактируй файл `.env`:

```
BOT_TOKEN=твой_токен_от_BotFather
DEEPSEEK_API_KEY=твой_ключ_от_DeepSeek
DEEPSEEK_BASE_URL=https://api.deepseek.com
DEEPSEEK_MODEL=deepseek-chat
```

Запуск:

```bash
python bot.py
```

## Пошаговая инструкция с телефона

### 1. Получи API-ключ DeepSeek (один раз)

1. Открой в браузере телефона: [platform.deepseek.com](https://platform.deepseek.com)
2. Зарегистрируйся / войди
3. Перейди в раздел **API Keys** → Create new key
4. Скопируй ключ

### 2. Подготовь файлы бота

Тебе нужен любой компьютер (или друг с компьютером), чтобы:
- Открыть папку `SexScenarioBot`
- В файле `.env` вставить свой ключ DeepSeek

### 3. Запуск бота

Самый простой способ для начала — запустить на компьютере:

```bash
python bot.py
```

Бот будет работать, пока компьютер включён и окно/терминал не закрыт.

Чтобы бот работал постоянно (24/7) — нужно задеплоить на сервер (Railway, Render, VPS).

### 4. Как пользоваться ботом в Telegram (с телефона)

1. Открой Telegram → найди **@SexScenarioBot**
2. Нажми **Запустить** или отправь `/start`
3. Один из вас нажимает **«Создать пару»** → получает 6-значный код
4. Отправляет код второму (просто текстом в личку)
5. Второй нажимает **«Присоединиться по коду»** и вводит код
6. Оба нажимают **«Начать новый сценарий»**
7. По очереди отвечаете на вопросы бота:
   - Предпочтения / кинки / настроение / табу
   - Место
   - Время
   - Роль (доминирую / подчиняюсь / по ситуации)
   - **Стиль** сценария
8. Когда оба заполнили — бот присылает готовый сценарий обоим
9. Под сценарием появляются две кнопки:
   - **🔄 Другой вариант** — новый сценарий в том же стиле
   - **🎨 Другой стиль** — выбрать другой характер и получить новый сценарий

## Важно

- После генерации предпочтения автоматически удаляются из базы.
- Данные для «другого варианта» хранятся временно в памяти бота (пока бот не перезапустится).
- Токен бота и ключ DeepSeek никому не отправляй.
